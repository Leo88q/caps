# Landing source & asset pipeline

`guttercaps-landing.html` в корне репозитория — **сборочный артефакт**. Правки делаются
только здесь, в исходниках, затем пересобираются:

```bash
npm run landing:build   # python3 scripts/landing/build.py  → ../..//guttercaps-landing.html
npm run landing:check   # числа против packages/economy + DOM-smoke (happy-dom, EN/RU)
```

Оба шага входят в `npm run verify`.

## Структура

| Файл | Роль |
| --- | --- |
| `content.py` | Весь копирайт EN/RU (`T`, `HOWTO`, `PACKS`, `FAQ`, `TIERS`, `TITLE`, `DESC`). 175+ i18n-ключей; каждый ключ обязан иметь RU-строку (`check.ts` падает, если нет). |
| `collections.js` | Районы × фишки для секции «Районы». Имена сверяются с `packages/economy/src/lore.ts` (сейчас 8 коллекций × 9 = 72). |
| `base.css` | Исходная визуальная система (`--wall-tint`, лампы; кирпичная текстура убрана — она прятала фоновые фото) — не редактируется без причины. |
| `extra.css` | Всё добавленное поверх: фото-стены, световые эффекты, бейджи, районные арты. |
| `app.js` | Рантайм: i18n, рендер районов/паков/тиров, счётчики, фото-reveal, курсорная лужа. `/*__DATA__*/` и `/*__COLLECTIONS__*/` заменяются при сборке. |
| `build.py` | Сборка: инлайнит CSS/JS/данные и **все изображения как webp data-URI** (файл остаётся самодостаточным — деплой = скопировать один HTML). |
| `check.ts` | Числа на странице против `packages/economy` (шансы, цены, комиссии, сплиты, имена). |
| `smoke.mjs` | DOM-тест собранного файла в happy-dom: рендер EN/RU, 8 районов / 72 фишки, ld+json, отсутствие ошибок. |

## Фото-фоны (`assets/`)

- `bg-*.webp` — AI-фоны секций (8 уникальных, переиспользуются в 11 секциях).
  Стилистика: мокрый ночном асфальт `#16151A`, неон районов (cyan `#16E5D9`, magenta
  `#FF2E8A`, orange `#FF7A1A`, acid `#B6FF3C`, ice `#9AD9FF`), без текста на картинке,
  запрещённый синий `#2E8BFF` не используется.
- `district-XX.webp` — контакт-лист 3×3 из **реальных мастеров** `art_drafts/master/XX-0..8.png`.
  Используется дважды: как миниатюра в карточке района и как **спрайт-лист каждого чипа**
  (`.chip-sprite` в `app.js` вырезает тайл капа через `background-position` — ноль лишних байтов).

Слои внутри секции: фон секции (`--wall-tint`) → `.wall-photo` (z:-1, «вуаль» читабельности
через `::after`, блик «мокрого асфальта» через `::before`, медленный дрейф Ken-Burns) →
контент → `.lamp-glow`. Всё гасится при `prefers-reduced-motion`; без JS фото показываются
через `<noscript>`-фолбэк.

### Бюджет веса

Собранный HTML ≈ 1,4 МБ, из них ~1,25 МБ — base64 изображений (бинарно ~950 КБ).
Правило: суммарный бинарный вес `assets/*.webp` ≤ 1 МБ; отдельный фон ≤ 130 КБ
(hero) / 85 КБ (секция) / 45 КБ (контакт-лист). Превысили — режьте разрешение,
не качество ниже ~q40.

### Перегенерация

1. Фоны: новые картинки в `art_drafts/site/`, затем пережать (пример — история коммита):
   `Pillow`, ресайз 1280–1672 px по ширине БЕЗ кропа (фото показывается целиком через `background-size: contain`), WebP `method=6`, качество под бюджет.
2. Контакт-листы: собрать сетку 3×3 из мастеров (TILE 160 / GUT 10 / PAD 14, фон `#16151A`).
   **Геометрия обязана совпадать** с константами `ART_TILE/ART_GUT/ART_PAD` в `build.py`
   (они попадают в рантайм как `DISTRICT_ART_GEO` и кормят спрайт-математику `app.js`).
3. `npm run landing:build && npm run landing:check` — оба должны быть зелёными.
