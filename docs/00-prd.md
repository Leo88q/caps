# GUTTERCAPS — Product Requirements Document (PRD)

> Фаза 0. Версия 1.0 · 2026-09-14 · владелец: продакт-лид
> Кодовое имя проекта в ТЗ — «Chip Collectibles»; рабочий бренд, уже зафиксированный в репозитории, лоре и на сайте — **GUTTERCAPS**. Далее используется он.

---

## 1. Видение

**Одной строкой:** коллекционная игра про «заряженные» крышки из ливнёвок вымышленного Gutter City, где каждая фишка — реальный on-chain актив на Solana, а редкость решается проверяемым VRF, а не сервером студии.

**Почему это не ещё один CapsGameBot:**

| Референс (CapsGameBot, Telegram mini-app) | GUTTERCAPS (Solana dApp Store, Android/Seeker) |
|---|---|
| Фишки — записи в БД бота | Фишки — Metaplex Core NFT в кошельке игрока; переживают закрытие игры |
| Рандом — на сервере, вера на слово | Switchboard On-Demand randomness; каждый дроп проверяем в эксплорере |
| Плоский UI, рандомные картинки | Единая вселенная: 8 районов × 9 тиров = 72 авторские фишки с лором и «+»-механикой «второго паводка» |
| Апгрейд = «нажми кнопку» | Fusion-верстак: 3 → 1, cross-district «перезарядка» и same-district «новая история» |
| PvP «кто больше кликнул» | Cap Slam: 3v3 сквады, элементы районов, best-of-3, серверный расчёт с публикуемым сидом |
| Токен без стоков | $CG с жёстким капом, бюджетной эмиссией и activity-guard: нельзя выпустить больше, чем экономика сжигает |

**Продуктовый принцип:** *«Граффити снаружи — бухгалтерия внутри».* Всё, что про эмоции (открытие пака, fusion, бой), — стрит-арт, шум, движение. Всё, что про деньги (баланс, цена, стейкинг, подтверждение), — «чистая зона»: моноширинный шрифт, сетка, ноль анимации. Правило уже зашито в `client/src/theme.css` (`.cg-clean-zone`) и является требованием к приёмке каждого экрана.

## 3. Пользовательские сценарии (ключевые)

### 3.1 Первые 10 минут (activation)
1. Открыл сайт/mini-app → **Hero: «Every drain holds a charge»** → CTA «Play».
2. Подключил кошелёк (MWA / Seed Vault на Seeker и Android; Phantom/Solflare/Backpack в web-превью на desktop) — цель ≤ 30 с.
3. Получил **бесплатный «Первый паводок»** — 1 гарантированная Common фишка Genesis-коллекции (soulbound 7 дней, нельзя продать — только играть).
4. Сыграл первый матч Cap Slam против бота-«Смотрителя» (обучение, всегда выигрышный).
5. Увидел Starter Pack за $1.49 с floor Rare → **конверсия в первую покупку** (цель 12 % в первые 24 ч).
6. Открыл пак — анимация с эскалацией по тиру (уже реализована в `PackRevealAnimation.tsx`).
7. Fusion-подсказка: «У тебя 3 Common — перезаряди их в Common+».

### 3.2 Ежедневная петля (retention)
Дейлики (логин → 3 матча → 1 победа → 1 fusion) ≈ 8 минут → 12 $CG → стейкинг/накопление на пак. Стрик 7 дней → фишка.

### 3.3 Недельная петля (monetization)
Сезон PvP (6 недель), weekly-квесты, дроп Limited Event Pack в пятницу 18:00 UTC («Партия одного дождя»), джекпот стейкинга по воскресеньям.

### 3.4 Сценарии, которые должны работать end-to-end (критерий приёмки из ТЗ)
`connect → buy pack → open pack (VRF) → see chip in collection → fuse dupes → list on market → play PvP → stake $CG → claim`. Каждый шаг покрыт e2e-тестом (см. `docs/06-acceptance-security-testing.md`).

## 4. Объём продукта

### In scope (v1.0 — mainnet launch)
- 72 фишки (8 коллекций × 9 тиров), Metaplex Core, on-chain `ChipState`
- 4 SKU паков + бандлы + pity, VRF Switchboard On-Demand
- Fusion 8 рецептов, бустеры
- Маркетплейс (list / buy / cancel / update price / offers-below-ask в v1.1), floor-трекинг
- Cap Slam PvP: ranked, casual, wager; сезоны; лидерборд
- Стейкинг $CG (4 тира) + стейкинг фишек + full-set бонус
- Квесты daily/weekly/permanent, реферальная программа
- Индексатор + REST API + админ-панель экономики
- Сайт (лендинг) + SEO
- **Solana dApp Store (Android / Seeker) — эксклюзивная платформа дистрибуции** (решение владельца Q8); web-билд остаётся для desktop-превью и маркетинга. Telegram Mini App — **вне scope** (Telegram = канал комьюнити)

### Out of scope (v1.x / v2)
- Гильдии/кланы, аренда фишек (scholarship)
- iOS-нативное приложение (App Store-политика по NFT — отдельный трек)
- On-chain PvP с полным commit-reveal каждого хода
- DAO-голосование $CG (Layer 4 роадмапа)
- Fiat-вывод

## 5. Ключевые метрики (KPI)

| Метрика | Определение | Цель M3 | Цель M6 | Бенчмарк |
|---|---|---|---|---|
| **D1 retention** | вернулся на следующий день после первой сессии | 40 % | 45 % | Web3-мидкор 30–38 %; топ-Telegram-игры 45–50 % |
| **D7 retention** | | 18 % | 22 % | Web3 12–15 % |
| **D30 retention** | | 8 % | 11 % | Web3 4–7 % |
| **Conversion to first pack** | доля новых кошельков, купивших ≥ 1 платный пак за 7 дней | 10 % | 14 % | F2P mobile 2–5 %; crypto-native 8–15 % |
| **ARPPU / мес** | выручка (USD) на платящего в месяц | $28 | $38 | Gacha mobile $25–45 |
| **ARPDAU** | выручка / DAU / день | $0.09 | $0.14 | |
| **Pack margin** | 1 − EV/price (взвешенно по SKU) | ≥ 30 % | ≥ 30 % | |
| **Marketplace take** | комиссия 5 % + роялти 2.5 % от объёма | — | $12k/мес | |
| **Sink ratio** | сожжено $CG / выпущено $CG за день | ≥ 0.5 | ≥ 0.8 | здоровые P2E ≥ 0.6 |
| **PvP participation** | доля DAU, сыгравших ≥ 1 матч | 55 % | 60 % | |
| **Fusion adoption** | доля D7-игроков с ≥ 1 fusion | 60 % | 70 % | |
| **Free share** | доля ценности фишек из бесплатных источников | ≤ 20 % | ≤ 20 % | инвариант `economy:check` |
| **Sybil rate** | доля кошельков, отфильтрованных антифродом при клейме | < 8 % | < 5 % | |

**Северная звезда:** *недельные активные кошельки с ≥ 1 транзакцией в игре* (не просто DAU — транзакция означает, что игрок дошёл до экономики).

### Обоснование целей
- D1 40 % выше среднего Web3 за счёт дистрибуции через dApp Store (кошелёк и SKR уже на устройстве, вход через MWA без seed-фразы), бесплатной первой фишки и обучающего матча с гарантированной победой (эффект «я уже что-то выиграл»).
- Конверсия 10–14 % — Starter Pack по цене кофе с +EV (114 % от цены при implied floor) и hard-gate «нужен Rare для fusion Rare+».
- ARPPU $28 — 4–5 Standard-паков или 2 Premium в месяц у медианного платящего; киты (топ-2 %) с Limited-паками и бандлами ×25 дают ~45 % выручки — стандартная кривая гачи.

## 6. Монетизация

| Источник | Валюта | Доля выручки Y1 (план) |
|---|---|---|
| Паки (Starter/Standard/Premium/Limited) | SOL / USDC / $CG | 70 % |
| Комиссия маркетплейса 5 % + роялти 2.5 % | SOL / USDC | 15 % |
| PvP rake 3 % с wager-матчей | $CG | 5 % |
| Бустеры/косметика (только за $CG — не за фиат) | $CG | 5 % |
| Коллаб-дропы (Season 4+) | SOL | 5 % |

**Что мы принципиально НЕ продаём за деньги:** бустеры fusion, силу в PvP, гарантированные Legend+/Diamond. Это ограничивает pay-to-win и держит нас в стороне от «инвестиционного контракта».

## 7. Риски и митигации

| Риск | Вероятность | Митигация |
|---|---|---|
| Регуляторный (loot-box = gambling в NL/BE/UK) | средняя | Публичные шансы в UI и on-chain; pity; гео-блок BE; 18+; юр-заключение до mainnet; $CG не продаётся в public sale |
| Смерть токена от инфляции | средняя | Бюджетная эмиссия + activity-guard (mint ≤ 30 % cap + 1.25 × burn); sink ratio на дашборде; квартальный ребаланс split |
| Sybil-фарм квестов | высокая | Device fingerprint + Turnstile + минимальный «возраст» кошелька + cap 2 бесплатных фишки/нед + soulbound-окна |
| VRF-даунтайм Switchboard | низкая | Таймаут 90 с → авто-refund (`cancel_stale_pack`); мониторинг очереди; ORAO как резервный провайдер за фичей |
| Rent-cost при масштабе | низкая | Metaplex Core (~0.0037 SOL vs 0.022 у Token Metadata); ChipState 8+~90 байт |
| Front-running открытия | низкая | Randomness account привязан к `PendingPack` в commit-транзакции; reveal permissionless |
| Компрометация oracle-ключа PvP | средняя | Oracle может выплатить только challenger/opponent (`InvalidWinner`), суточный лимит выплат, ротация ключа через мультисиг |
