фоны, баннеры, иконки, лендинг, пакет для dApp Store и экспорты для NFT.

`scripts/asset-inventory.py` (геометрия/формат/покрытие) и `scripts/asset-visual-qa.py`

Сырые метрики: `reports/asset-inventory.json`, `reports/asset-visual-qa.json`.
Контактные листы для ручного просмотра: `reports/contact-masters.png` (все 72, 150 px),
`reports/contact-56.png` (тест читаемости 56 px из §2.1).

(296.5 КБ gzip ≤ 350 КБ бюджета), `landing:check` (все проверки пройдены),
и на прогнанном through-HTTP `vite preview` — каждый ассет отвечает 200.

## 3. Мастеры: сверка с чек-листом приёмки (docs/07 §7)

Проверено все 72 файла, по каждому — 6 пунктов чек-листа:

| Требование | Результат |
|---|---|
| 2048×2048, PNG-32 | ✅ 72/72 |
| Режим RGBA | ✅ 72/72 |
| Диск Ø 1792 (87.5 %), центр в центре | ✅ 72/72, bbox ровно 1792×1792, смещение центра `dx=dy=0.0` px |
| Круг, не эллипс | ✅ aspect 1.0000 у всех 72 |
| Альфа бинарная: 0 снаружи / 255 внутри | ✅ полупрозрачных пикселей **0.000 %** у всех 72 |
| Доля непрозрачного 60.13 % (= π/4 · 0.875²) | ✅ 60.15 % у всех 72 — диск ровно вписан |

Дополнительно: запрещённый в арте trust-blue `#2E8BFF` — максимум **0.039 %** пикселей
(это противоотождествлённый циан на кромке, не заливка); яркость лица диска 21–115 из 255
(нигде не «выжигает» сетку, но разброс большой — см. §5.3).

Два отклонения от буквы спеки, оба низкого приоритета:

- **D1 · нет встроенного ICC-профиля.** §2 требует sRGB IEC61966-2.1 в файле; у всех 72
  профиля нет. Пиксели при этом в sRGB-диапазоне, браузеры трактуют как sRGB, визуальной
  разницы нет. Правится одной командой `convert … -profile sRGB.icc` в конце пайплайна.
- **D2 · край диска без антиалиасинга.** §2 просит «антиалиасинг 1–2 px», фактически
  маска пороговая (0 % полупрозрачных). В производных 256/512 webp сглаживание
  появляется само при ресайзе (альфа там 0–255), так что в игре это не видно.
  Проявится, если печатать NFT-карточку прямо из мастера в 2048 px.

## 6. Производные, которые реально грузятся

### 6.1 Фишки в игре — ✅

`client/public/art/` — 144 файла = 72 × {256, 512}:

- геометрия: диск вплотную к краю квадрата, bbox = весь холст, **углы полностью прозрачные**;
  доля непрозрачного 0.779 / 0.782 (вписанная окружность, π/4 = 0.785) — ровно по §4;
- бюджеты §4 соблюдены с запасом: 256 px — 16.6–28.3 КБ (бюджет 40), 512 px — 51.3–99.5 КБ (бюджет 120);
- альфа сохранена (0–255), WebP RGBA.

**Отсутствует третий размер из §4 — `…-1024.webp` (72 файла).** В игре он сейчас не нужен
(максимальный показ — страница фишки 330 px), но нужен будет для reveal и для NFT-превью.

### 6.2 Фоны и баннеры — ✅, но ratio не выровнены

- `/bg/`: 13 файлов. Два webp (арена, кодекс) — 1672×941, одиннадцать jpg — 1376×768.
  Смешанные пропорции (1.78 vs 1.79 — почти одно и то же, но не одинаково).
- `/districts/`: 8 jpg. Семь — 1200×509, но `04.jpg` — 1200×670, `05.jpg` — 1200×396.
  В Кодексе они кропаются CSS (`height: 150px; object-fit: cover`), поэтому `05`
  обрежется сильнее остальных и сцена будет кадрирована не так, как задумано.
  Причина в исходниках: `art_drafts/site/banner-04.png` 1376×768, `banner-05.png` 1792×592,
  остальные 1584×672. Перегененить баннер 05 (и подровнять 04) — 2 кадра.

Все ссылки из кода резолвятся: в собранном `dist` 38 абсолютных ссылок на ассеты,
битых — одна (`/og.png`, см. §8.1). По HTTP всё остальное отвечает 200 с правильным MIME.

### 6.3 Метаданные и OG приложения

- `client/public/manifest.json` — валиден, иконки 192/512 на месте, `theme_color #16151A` совпадает с темой.
- PWA-иконки без альфа-канала (требование dApp Store) — ✅ подтверждено.
- `client/public/fonts/` — пуста (только README), но шрифты в бандл всё равно попали:

  системным шрифтом, а не Inter. Заметно рядом с кастомными заголовками.

## 8. Битое и отсутствующее прямо сейчас

### 8.1 `/og.png` — битая OG-картинка приложения
`client/index.html:10` → `<meta property="og:image" content="/og.png" />`.
Файла нет. `location /` в nginx и SPA-fallback отдают на этот URL **index.html с кодом 200**,
поэтому в браузере это выглядит тихо, а все соцсети и превью-боты получают HTML вместо
картинки и показывают пустой прямоугольник. Нужно 1200×630.

### 8.2 `og-guttercaps.png` — то же самое для лендинга
`guttercaps-landing.html` и `scripts/landing/build.py:182` ссылаются на
`https://guttercaps.gg/assets/og-guttercaps.png` (1200×630). Файла ни в репозитории,
ни в `scripts/landing/assets/` нет.

### 8.3 Медиа для Publisher Portal — 0/6
`dapp-store/media/` пуст. Нужны `icon-512.png` (есть — достаточно скопировать из
`client/public/`), `banner.png` 1200×600 и минимум 4 скриншота 1080p с реального
устройства. Скриншоты — единственное, что нельзя сделать в этой среде (нужен живой
APK на девайсе); остальное делается из того, что уже есть.
