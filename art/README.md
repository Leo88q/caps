# art/ — приёмка арта фишек (90 мастеров)

Это **инбокс и журнал**, а не финальный арт. Владелец присылает кадры партиями по 5; здесь фиксируется,
что именно пришло, какому району и тиру оно соответствует, и что нужно сделать, чтобы из презентационного
кадра получился игровой ассет по `docs/07-art-spec.md` (там же — палитра, форма мастера и экспорт §4).

## Раскладка

| Путь | Что это | В гите |
|---|---|---|
| `art/inbox/` | файлы как пришли, с исходными именами | нет (сырьё) |
| `art/manifest.json` | журнал: одна запись на кадр, ключ `{district:02}-{tier}` | да — это источник сводки «90/90» |
| `art/masters/` | нормализованные мастера 2048² (кроп диска, альфа) | нет (дальше — CDN) |
| производные `game/*.webp`, `nft/*.png`, `og/*.jpg` | экспорт по `docs/07-art-spec.md` §4 | нет (CDN) |

Ключ записи: `01-0` … `10-8` (`district` 01…10, `tier` 0…8). Имя тира и лор-имя чипа берутся из
`packages/economy/src/lore.ts` — не из подписи на картинке: подпись может отстать, лор-файл не может.

## Что проверяется на каждом кадре

1. **Соответствие**: район и тир читаются; сюжет поддерживает лор-имя тира (например `02-6` Legend = «Bone Leg» — бинт на ноге).
2. **Форма**: квадрат, диск строго сверху, без наклона (`docs/07-art-spec.md` §2).
3. **Фон/тень/свечение**: для NFT-карточки их печёт пайплайн — кадр с фоном годится; для игрового диска нужен вырез с альфой.
4. **Запечённый текст на ободе**: для NFT/промо — нормально; для игры — нет (имя и редкость рисует UI на 11 локалях).
5. **Тон лица диска**: тёмное семейство asphalt `#16151A…#2A2830` (`docs/07-art-spec.md` §2.2); светлое лицо «выжигает» сетку на тёмных экранах.
6. **Палитра района** против `lore.color` (для 02 — orange): дрейф фиксируется, не блокирует.
7. **Размер мастера** ≥ 1600² и альфа: проверяется, когда файл лежит на диске (сейчас кадры приходят вложением в чат).

Вердикт по кадру — `ok`, `ok с правкой` или `нужна перегенерация`, с указанием, что именно. Итоговая
сводка (сколько принято, чего не хватает по районам и тирам, какие решения нужны) собирается один раз,
когда придут все 90.
